# AI Gesture Recognition Device
AI-powered gesture recognition using a 3‑axis accelerometer (LIS3DH) and on‑device classification to map vibration/gesture patterns to keyboard keys via USB HID.

This repo contains two Arduino sketches:
- `accelerometer_datalogger_1.ino` — streams raw accelerometer data over Serial for collecting training data.
- `accelerometer_main_1.ino` — runs an embedded classifier (NanoEdge AI) and sends keystrokes (e.g., Page Up/Down) when gestures are recognized.


## Features
- Real-time 3‑axis acceleration sampling (100 Hz, ±4 g)
- Sliding window buffer of 256 samples
- Data logging over Serial for model training
- On-device classification with NanoEdge AI Studio generated model
- USB HID keyboard output (e.g., Page Up / Page Down)


## Hardware
- Microcontroller with USB HID support (tested with boards that support `Keyboard.h` such as Arduino Leonardo/Micro, SAMD, or similar)
- LIS3DH 3‑axis accelerometer (I²C)
- Jumper wires and breadboard (as needed)

Notes:
- The sketches use I²C address `0x18` for LIS3DH. If your sensor is at `0x19`, update `SENSOR_I2C_ADDR`.
- The code uses `Wire1` in the LIS3DH constructor. If your board exposes only `Wire`, change `Adafruit_LIS3DH lis = Adafruit_LIS3DH(&Wire1);` to use `&Wire`.


## Software and Libraries
Install these via Arduino Library Manager unless noted:
- Adafruit LIS3DH: [Adafruit_LIS3DH](https://github.com/adafruit/Adafruit_LIS3DH)
- Adafruit Unified Sensor: [Adafruit_Sensor](https://github.com/adafruit/Adafruit_Sensor)
- Keyboard (bundled with many HID-capable cores): [Arduino Keyboard](https://www.arduino.cc/reference/en/libraries/keyboard/)
- NanoEdge AI (header and knowledge array generated by the desktop tool): [ST NanoEdge AI Studio](https://www.st.com/en/development-tools/nanoedgeai-studio.html)

Arduino IDE: 1.8.x or 2.x


## Wiring (I²C)
- Connect `VCC` → 3.3 V (preferred) or 5 V per your LIS3DH breakout
- `GND` → GND
- `SDA` → board I²C SDA
- `SCL` → board I²C SCL
- Optional: Pull SDO to GND for I²C address `0x18` (to VCC for `0x19`)

Consult your board’s pinout for SDA/SCL and whether to use `Wire` vs `Wire1`.


## Repository Structure
- `accelerometer_datalogger_1.ino` — capture 256×3 samples at 100 Hz and print to Serial (115200 baud)
- `accelerometer_main_1.ino` — classify a 256‑sample window and emit keystrokes
- `knowledge.h` — model parameters generated by NanoEdge AI Studio (not included; you must add this file after training)


## Quick Start
1. Install Arduino IDE and required libraries (above).
2. Wire the LIS3DH to your board via I²C.
3. If your board does not have `Wire1`, replace `&Wire1` with `&Wire` in both `.ino` files.
4. Select a USB HID-capable board in Arduino IDE (e.g., Arduino Leonardo).


## Collect Training Data (Data Logger)
1. Open and upload `accelerometer_datalogger_1.ino`.
2. Open Serial Monitor/Plotter at 115200 baud.
3. Perform each gesture for a few seconds; copy the printed lines to a file for labeling.
   - Each cycle prints a window of `256 × 3` values in the order `x y z ...`.
4. Build a dataset with multiple examples per gesture and “background/idle” data.


## Train a Model (NanoEdge AI Studio)
1. Import your labeled dataset into ST’s NanoEdge AI Studio.
2. Configure three-axis vibration input, window size 256, sampling 100 Hz, ±4 g.
3. Train and export a classification library and `knowledge.h`.
4. Place the generated `knowledge.h` in the same folder as `accelerometer_main_1.ino`.

Tip: If your Studio export targets a different buffer or axis count, align the macros in the sketch.


## Run the Classifier and Send Keystrokes
1. Open `accelerometer_main_1.ino`.
2. Ensure the following match your setup:
   - `SENSOR_I2C_ADDR` (default `0x18`)
   - `SENSOR_DATA_RATE` (default `100 Hz`)
   - `SENSOR_RANGE` (default `±4 g`)
   - `SENSOR_SAMPLES` (default `256`)
3. Upload to your HID-capable board.
4. Move/gesture the device; the model predicts a class and sends keys:
   - Class `1` → `KEY_PAGE_DOWN`
   - Class `2` → `KEY_PAGE_UP`

You can customize the mapping by modifying the conditional in `loop()`:

```cpp
// Example: map your class IDs to keystrokes
if (id_class == 1) {
  Keyboard.write(KEY_PAGE_DOWN);
} else if (id_class == 2) {
  Keyboard.write(KEY_PAGE_UP);
} else if (id_class == 3) {
  Keyboard.write('N'); // any key or combo you prefer
}
```

To test without HID, set `NEAI_MODE` to `0` to print raw samples instead of classifying.


## Configuration Reference
Key macros used in both sketches:
- `SENSOR_I2C_ADDR` — I²C address (`0x18` or `0x19`)
- `SENSOR_DATA_RATE` — output data rate (`LIS3DH_DATARATE_100_HZ`)
- `SENSOR_RANGE` — full-scale range (`LIS3DH_RANGE_4_G`)
- `SENSOR_SAMPLES` — window size (default `256`)
- `AXIS` — number of axes (3)


## Troubleshooting
- Compile error: unknown `Wire1` — switch to `&Wire` in the LIS3DH constructor.
- No sensor found / hangs in setup — check wiring and I²C address; verify pull-ups and power.
- Wrong I²C address — toggle LIS3DH SDO pin (`0x18` vs `0x19`) or change `SENSOR_I2C_ADDR`.
- No keystrokes on PC — ensure the board supports USB HID and `Keyboard.begin()` is called.
- Unstable predictions — collect more diverse training data or tune window size/range/rate.


## Safety and Etiquette
- Sending keystrokes can control your active computer session. Test in a safe environment to avoid unintended actions.
- Consider adding an arming gesture or a physical switch before enabling HID output.
